# Q1 需求与验收 QE 评审

在 Q1 读取。本参考把需求或 PRD 检查为可测试、可交接的产品契约；它不替代产品评审，也不决定用户价值、优先级或预算取舍。

## 输入

- 当前需求、PRD 或规划文档；
- 用户已确认的目标、范围、非目标和约束；
- 当前产品/代码事实及仍有效的历史验收；
- 已知权限、数据、外部副作用、成本和人工介入边界。

文档不要求固定文件名。多份文档可以共同构成权威输入，但必须标明各自负责的事实；冲突内容不得静默合并。

复用前序产品讨论、假设检查或 grilling 已确认的决定和已有证据；仍待验证的内容进入本门的“未验证与假设”，不能因讨论达成一致或已写入文档而视为事实。转入 Q1 不重复访谈、不重新确认未变化的决定。

## 检查范围

1. 目标、用户任务、范围和非目标是否可区分；
2. 关键术语、输入、输出、状态和完成标志是否有明确含义；
3. 每条核心承诺能否转成可观察结果；
4. 是否覆盖必要的正常、失败、边界、恢复和禁止行为；
5. 权限、数据来源、外部写入、成本和人工接管是否有边界；
6. 是否能推导最小测试案例、证据方式和后续 Harness 入口；
7. 需求是否把产品选择、工程方案和未验证假设混在一起；
8. 变更是否影响既有契约，是否需要从本门或更早门禁重入。

不要为了 Q1 通过而提前穷举所有测试，也不要把技术实现偏好升级成产品必选项。非关键缺口可以登记假设并继续；关键缺口按 [产品指南第 7 节](../../../ai-guides/ai-pm-distillation.md)区分查证、产品决策和实验验证，只暂停依赖该缺口的范围，不把事实缺口一律交给用户决定。

## 输出

```markdown
# Q1 需求 QE 评审

- 批次：
- 审查范围：
- 门禁：Passed / Passed for limited scope / Changes required / Review incomplete
- 产品评审状态：已确认 / 待确认 / 不在本次范围

## 验收矩阵
| 核心验收项（已有 ID/锚点及目标） | 可观察结果 | 禁止结果 | 后续验证方式 | 状态 |
|---|---|---|---|---|

## Findings
- 编号、严重程度、违反的需求、失败条件、影响、证据和建议

## 未验证与假设

## 下一门禁
```

## 验收矩阵的阶段续填

验收矩阵是同一组核心验收项的可续填关系，不是每个门禁重新复制一套记录。每条核心项沿用已有需求 ID、验收 ID 或稳定交接锚点；没有现成 ID 时才创建本批稳定标识。保留“正常结果”和“禁止结果”，并按阶段补齐下列关联：

| 关系字段 | Q1 需求评审 | Q2 架构/研发评审 | Q3 测试与 Harness 评审 | Q4 实现与交付 |
|---|---|---|---|---|
| 核心验收项 | 定义目标、正常结果、禁止结果和边界 | 沿用原项，不重复定义 | 沿用原项，不重复定义 | 沿用原项，不重复定义 |
| 系统落点 / 实现任务 | 留空或引用已有需求/设计文档 | 补模块、数据、状态、契约落点；任务拆分时引用任务 ID | 沿用落点，核对入口覆盖范围 | 记录实际受影响代码/产物 |
| 验证方法 / 实际入口 | 只定义验证方向和所需证据类型 | 补设计层面的验证策略或依赖 | 补已核实入口，或登记入口建设任务、判定条件和责任 | 沿用入口并记录实际运行方式 |
| 实际结果 / 版本 / 证据 | 无现有结果时待补；已有有效证据可引用 | 引用已有证据及本阶段可行性验证结果 | 引用已有或本阶段入口验证结果；入口存在不等于已运行 | 补本批实际结果、源码/构建版本、运行证据和结论，复用仍有效证据 |
| 未验证状态 | 标明未知假设和不适用范围 | 标明受设计或依赖影响的未验证项 | 标明未运行、未覆盖或入口尚未就绪 | 保留仍未验证的边界，不以映射存在代替验证 |

矩阵中的字段可以链接已有需求、架构、任务、执行或证据文档；复杂项目可以拆成多张相互链接的表，只要核心项到落点、入口、结果和未验证状态的关系可核查。状态和链接由现有单一记录者维护，执行者保留自己的原始证据文档，主记录只引用其入口。

存量项目已有有效资料和门禁结论时继续沿用，不因新增关系字段回到 Q1，也不要求全量迁移；只补本批受影响的核心项。映射存在不等于验证通过，实际结果须有对应行为与版本的可复核证据；不限定证据产生于哪个门禁，也不能用计划或占位内容代替结果。

Q1 通过只表示可以进入 Q2 架构设计。没有通过的产品取舍不能由执行者在实现时自行决定。
