# Harness 就绪与增量验证

在方案与执行交接阶段确定验证入口，或在实现与修复阶段选择验证方式、判断交付就绪时读取。输入是权威契约、执行任务和当前项目事实；输出是可复用的运行入口、验证证据和未验证边界，供审查与放行引用。Harness 是能够运行并获得可靠反馈的环境；命令、依赖和构建关系从当前项目查证，授权沿用启动契约。执行者必须能直接获得反馈并据此修复；由主模型逐次解释失败、派发修补，不算执行者自主loop就绪。阶段交接、恢复和工程失败计数按 [交接与恢复](handoff-recovery.md) 执行。

## Q3 测试设计门禁

Q3 评审的是“如何验证将要实现的行为”，不是要求功能在实现前已经通过端到端测试。对于尚未实现的行为，必须提供可观察契约、最小验证入口建设任务、预期证据和未来回归范围；不能把“当前没有实现”当作运行失败，也不能把测试文件存在当作入口可用。

验收矩阵的阶段续填约定见 [需求与验收 QE 评审](requirements-review.md)。Q3 在既有核心验收项上补已核实的实际入口，或补入口建设任务、判定条件和责任；入口或映射存在不等于已验证。已有有效结果继续引用，Q4 补本批实际结果、版本和证据。

缺少完整验证能力时，可以用 `Passed for limited scope` 进入声明范围内的 Q4，并把入口建设列为执行任务。若连最小入口、判定方式或关键副作用都无法定义，则依赖该入口的范围为 `Changes required`。

## 就绪程度

**H1 可运行**：当前入口可构建或启动，配置有权威来源，错误可观察，测试资源可隔离和恢复。实际运行证据不能由脚本存在代替。

**H2 可验证**：当前行为具有可重复的验证入口，依赖采用真实实现或可信替代，能观察结果与副作用并归因失败。缺失验证能力时，把最小入口建设作为明确任务，不要求先建完整测试平台才能实现。非确定性输出使用代表样本和明确判定方式。

**H3 可验收**：核心任务从真实入口完成，重要失败与恢复已有证据，人工验收和未验证范围明确。工程证据不替代真实模型质量与用户价值判断。

## 执行文档中的验证检查项

每批交接写清下列信息，已有有效约定直接引用。按风险选择适用内容，不强制每批运行所有测试层级，也不要求提前穷举全部用例：

| 检查项 | 执行文档应提供的信息 |
|---|---|
| 运行方式 | 工作目录、环境与必要依赖、已核实的构建／测试命令或脚本入口；测试数据或可信替代及隔离边界 |
| 必须证明的行为 | 对应需求或风险的可观察结果、关键副作用及禁止结果；正常与必要的失败、恢复、兼容场景 |
| 最低验证范围 | 应运行的现有测试集、需补的行为验证、受影响的相关回归及选择依据；执行者可按新证据补充 |
| 通过与停止条件 | 哪些结果必须成立、哪些失败阻塞本批、哪些检查不适用及原因；不能只写“编译通过”或“所有测试绿灯” |
| 失败处理 | 日志／失败输出入口；普通缺陷在执行者循环内修复重跑；契约缺口、授权外操作、预算与无进展按主流程上报 |
| 交付证据 | 实际差异、对应源码／构建产物的运行结果、覆盖行为、未验证范围及剩余阻塞 |

尚不存在验证入口时，交接中明确由谁先建立最小入口及其完成标准，不编造命令，也不把未运行的入口标为可用。优先复用已有脚本与测试，不默认开发专用写入器或测试平台。

## 选择与执行

执行者先验证入口可用，再用该入口完成实现、自测和修复。验收标准来自已确认需求；不能为了通过而削弱断言，测试本身有误时须提供独立依据。

首个可运行版本先检查真实入口及核心用户任务，涉及视觉则立即对照已确认设计，再扩大相关行为覆盖。外部能力先验证最小可用性，避免长流程建立在无效环境上。

每项验证对应验收或具体风险，选择最低成本的充分证据；跨层测试须证明不同失败可能，不默认复制同一矩阵。明确源码与构建产物的依赖，先完成必要构建，再做产物验证；未失效的既有证据继续有效。

独立用例自行准备前置状态，支持定向运行；连续旅程作为完整场景表达，不拆成隐式顺序依赖。失败先定位到受影响用例，修复后运行相关回归，达到验收即停止。具体运行范围由变更影响决定，不以通过项数量作为收口目标。

验证设施持续产生无关失败时，由执行者先定位路径、依赖、配置或产物问题；需要超出权限的环境修改才上报。优先复用可信入口或采用可复核的更简单证据，不静默降低已确认验收。普通缺陷留在所属执行循环，持续无进展按主流程诊断，只有证据推翻契约时重入设计。

## 交付证据

在既有记录中说明实际入口、源码版本或必要文件指纹、对应构建产物、结果、覆盖行为、未验证范围和剩余阻塞；沿用已有日志，不要求每轮全仓哈希或另建证据系统。独立验收者可直接复用这些入口，主模型不必充当测试运行中转。人工发现缺陷先稳定复现，再以与风险匹配的回归方式验证；不为每个低影响改动强制建设新自动化。
